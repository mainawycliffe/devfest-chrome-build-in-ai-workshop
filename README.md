# ✨ PostCraft AI

Transform your social media posts with AI-powered writing enhancements. PostCraft AI helps you create engaging, professional content with grammar checking, text polishing, and intelligent hashtag generation.

## 🚀 Features

- **Grammar Check** - Fix spelling, grammar, and punctuation errors instantly
- **Polish** - Transform text into professional, engaging content
- **Elaborate** - Add depth and detail to your posts
- **Shorten** - Make your content concise and impactful
- **Hashtag Generator** - Get relevant hashtags for maximum reach
- **100% Private** - All processing happens on your device using Chrome's built-in AI
- **Works Offline** - No internet connection required after initial setup
- **Real-time** - See improvements as they're generated

## 🎯 Perfect For

- Social media managers
- Content creators
- Bloggers and writers
- Marketing professionals
- Anyone who wants to improve their writing

## 🛠️ Technology

Built with:
- **Angular 20** - Modern web framework
- **Chrome Built-in AI** - On-device Gemini Nano model
- **TypeScript** - Type-safe development
- **Responsive Design** - Works on all devices

## 📋 Requirements

- Chrome Canary/Dev 128+ with Prompt API enabled
- Enable these flags in `chrome://flags`:
  - `#prompt-api-for-gemini-nano`
  - `#optimization-guide-on-device-model`
- Restart Chrome after enabling flags

## 🚦 Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser to `http://localhost:4200`

4. Download the AI model when prompted (one-time, ~1.5GB)

5. Start crafting amazing posts!

## 📦 Build

```bash
npm run build
```

Built files will be in `dist/postcraft-ai/`
